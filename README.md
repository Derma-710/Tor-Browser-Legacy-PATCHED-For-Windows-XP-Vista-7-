# Tor-Browser-Legacy-PATCHED-For-Windows-XP-Vista-7-
This is a fork of Mypal. It is modified with some extensions. It uses Ublock and Onion Browser Button. It was made to connect to Tor Network. A legacy browser with Tor so people that are using Windows XP/Vista/7 can connect to Tor without using older versions of Tor Browser.

NEW INTRODUCTION (October 8, 2026):
The old Tor Browser from 2010 used old Firefox from 2010, Vidalia, Privoxy, Tor Bundle, Tor Button and Polipo.
The Tor-Browser-Legacy-Patched is a cool project that tries to remake the old Tor Browser.
Tor-Browser-Legacy-Patched removed old Firefox 2010 with Mypal browser.
It still uses: Vidalia, Privoxy, Tor Bundle and Polipo.
The Tor Button was replaced by an unnoficial extension called: ”Onion Browser Button”.
So this project partially simulates what old Tor should look like, and it s patched so no vulnerability comes in.
